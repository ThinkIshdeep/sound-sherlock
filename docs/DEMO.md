# Demo walkthrough

The video is a 21-second captioned sequence of three screenshots captured from the V2 application. The QA host uses the same standalone view and engine. This is an edited walkthrough, not a continuous real-time recording.

## 1. Inspect a normal reference

The app displays a synthetic recording, waveform, spectrum and recording-quality checks.

## 2. Compare an anomalous sample

An added spectral component changes the anomaly score. A transparent baseline is compared with Isolation Forest.

## 3. Test changed background noise

A noise-shift sample probes sensitivity. These results are synthetic and do not identify real machine faults.
